# TRAIL CHAOS — SIDE TRAIL V5.2

## Atelier du personnage
- Nouvelle page `atelier-perso.html`, accessible depuis l’accueil et la boutique.
- Réglages des proportions : taille générale, tête, foulée, balancement des bras et gilet.
- Personnalisation des couleurs du tee-shirt, short, casquette, chaussures, cheveux et peau.
- Retouches pixel-art directement au doigt (300 pixels maximum), gomme et annulation.
- Aperçu animé des mouvements course / saut / accroupissement, en réutilisant les fonctions du sprite du jeu.
- Les modifications sont sauvegardées sur le même navigateur dans `trail-chaos-character-v1` et appliquées en course sur l’écran de jeu.
- Export JSON pour partager sa création et éventuellement définir une nouvelle apparence officielle dans GitHub.
- Les objets collectors prioritaires gardent leur couleur lorsque équipés. Les pixels peints concernent les poses debout et saut ; pour l’accroupissement, les proportions et couleurs natives restent actives.
- L’ancienne version V5.1 est archivée dans `side-v51.html`.

## Sauvegardes
La progression historique `trail-chaos-runner-v2`, la boutique, les parcours et les défis sont conservés. Le code de dessin reste original.
