# TRAIL CHAOS V5.9 — Storyboard Millau intégré

La course utilise les cinq décors WebP découpés du storyboard validé, sans titre ni chemin fixe dans le fond. Les fonds défilent à la position du joueur, sans fondu.

| Section | Sol et relief |
| --- | --- |
| 0–5 km | Vallée du Tarn, sentier doux |
| 5–10 km | Montée rocheuse et route d’accès |
| 10–15,7 km | Tablier du viaduc presque horizontal |
| 15,7–20 km | Causse Rouge, terrain minéral |
| 20–23,7 km | Descente et arrivée avec public |

Le sol jouable est un calque indépendant, aligné avec la physique et les obstacles. Les animations de la V5.4 et les sauvegardes sont conservées. Le profil altimétrique est **une approximation de jeu, pas un relevé GPS réel**.

Images : `assets/millau/storyboard-1.webp` à `storyboard-5.webp`. Ancienne V5.8 archivée dans `side-v58.html`.
